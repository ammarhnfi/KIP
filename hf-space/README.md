# Komisi Informasi Terdekat

Peta interaktif Komisi Informasi (KI) di Indonesia beserta dua KI terdekat untuk tiap objek.

- Peta OpenStreetMap dan citra satelit Esri World Imagery (gratis).
- Klik baris tabel atau titik di peta: peta otomatis zoom ke objek dan dua alternatifnya.
- Tombol "Unduh Excel" membuat file `KI-terdekat.xlsx` berisi tabel dan sheet "Peta" bergambar sebaran KI.

Seluruh aplikasi ada di `index.html`. Untuk memperbarui data, ubah array `K` di dalam file itu.
